# Experiment 1 implementation design

The supplied research specification is the experiment contract. The user approved
implementation and requires one Bash entrypoint running every stage, without
installing libraries or modifying the existing Colab/Torch environment.

Use independent Python processes for preparation, parity generation/replay,
clean generation, feature extraction, bridge fitting, held-out validation,
delta calibration, perturbation smoke testing/generation, finite-difference
analysis, native tangent diagnostics and report generation. All generated
responses come from batched offline vLLM. Persist exact token IDs and frozen
revisions. Any missing dependency, malformed artifact or failed mandatory
runtime check exits nonzero; an inconclusive scientific result is reported as
such rather than called a successful fingerprint.

Reuse the locally available vLLM v0.20.0 public logits-processor interface,
SciPy statistics/linear algebra, sklearn PCA/Ridge and Sentence Transformers.
KSRF-specific score accumulation, Fisher whitening, keys and diagnostics are
implemented directly. Never copy unrelated fingerprint heuristics.

Default full run: 5000 calibration / 1500 held-out; 16 keys; 2000 bootstrap
replicates; independent finite differences start at 500 held-out prompts and
expand to 1500 if uncertain. Resource settings change batching only.

User amendment: the Bash runner must enter the experiment directly, without an
environment/import preflight. Diagnostics are now standalone explicit commands;
the 14-stage runner retains scientific score/parity/EOS checks and records actual
runtime provenance while generating clean trajectories.

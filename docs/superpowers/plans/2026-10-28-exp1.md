**Goal:** Deliver and push a complete Colab-safe Experiment 1 implementation.

**Architecture:** Process-isolated GPU stages exchange versioned JSON/NPZ
artifacts. Frozen calibration transforms are applied to held-out samples.

**Tech Stack:** vLLM 0.20.0, PyTorch (preinstalled), Transformers,
Sentence Transformers, NumPy, SciPy, scikit-learn, datasets, Hugging Face Hub.

**Spec:** docs/KSRF_Experiment_1_Code_Spec.md

## Global constraints

- No installation or Torch/environment changes in run_colab.sh.
- No generation backend except offline batched vLLM.
- 5000 train_gen and 1500 test_gen unique prompts; no held-out fitting.
- Seeds: selection 20261028, sampling 731000 + index, projection 1123, key 4417.
- Preserve sampled EOS; never append EOS to capped generations.
- Temperature 0.8; bias before temperature is 0.8 * eta * F_vocab @ w.
- Store exact checkpoint/tokenizer/encoder/dataset revisions and runtime versions.

## Task 1: Runtime and extraction

Files: data.py, clean_rollouts.py, vllm_logit_processor.py,
validate_vllm_parity.py, readout_features.py, replay_scores.py,
semantic_features.py, validate_tangent.py. Build real runtime checks for
temperature, EOS, batching, distribution parity and request isolation.
Execute temporary CPU checks before final integration; GPU-only checks run
as mandatory stages in the delivered entrypoint.

## Task 2: Statistical analysis

Files: fit_bridge.py, key_and_statistic.py, validate_gradient.py,
validate_fd.py, mathematics.py. Verify score-function identity by exact
enumeration before implementing bridge and validation. Use SciPy bootstrap
and principal angles; sklearn PCA/Ridge. Preserve both raw and residualized
scores, half-split stability, shuffled/random baselines and key diagnostics.

## Task 3: Full runner and reporting

Files: config.yaml, common.py, __main__.py, preflight.py, report.py,
run_colab.sh, requirements.txt, README.md. Use subprocesses to release VRAM.
Preflight never installs anything. Check all required artifacts and evidence
before writing a scientific decision. Run syntax, mathematical and synthetic
integration validation; review actual diff, resolve findings, publish to GitHub.
